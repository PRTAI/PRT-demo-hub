# 登录页动画与本地预览

森林／松鼠视频全屏静音播放，顺序固定为：完整视频一次（约 10 秒）→ 松果落地、弹跳并静止一次（约 3 秒）→ 草叶轻摆循环（每轮约 4 秒）。最后的循环中，松果、树木与镜头保持固定。登录入口以小幅暖色半透明纸张浮层显示，使用细颗粒、柔和模糊和轻阴影融合场景；桌面和手机都保持完整背景。

每次打开登录页，约 1.8 秒后开始显示界面：品牌先淡入，登录浮层以约 2.6 秒的缓动逐渐清晰并轻移到位，按钮和页脚稍后跟随。界面入场与背景播放独立，登录无需等待整段视频结束。

完整视频真正播完后才切换松果落地片段，后者从原视频开头截取至约 2 秒松果静止处，首尾留有短暂停留。后续片段开始播放后再淡出上一层，避免加载时闪黑；落地片段结束的构图与草地循环一致。草地循环取自原视频约 2–3 秒的片段，放慢后往返衔接，并固定松果及背景区域。页面不提供暂停、重播或跳过动画按钮。转到后台时自动暂停，返回后从当前阶段继续。

视频失败或自动播放被浏览器阻止时，显示静态封面，登录仍然可用。系统开启“减少动态效果”时直接显示静态页面。本地的“功能体验”身份选择默认收起，点击后展开。

## 本机查看（macOS）

需要 Node.js 24 或更高版本。终端执行：

```bash
cd /path/to/PRT-demo-hub
npm ci
npm run dev
```

已有完整 `node_modules` 时可跳过 `npm ci`。终端保持运行，然后打开：

- 登录页：<http://127.0.0.1:5173/>
- 预览链接（刷新即可从头查看固定流程）：<http://127.0.0.1:5173/?intro=1>

已进入演示工作台时先退出登录。开发预览会额外显示“功能体验”和身份选择区，未配置飞书时显示配置提示，均属于本地预览的正常行为。正式环境沿用原有飞书登录。

开发服务仅绑定本机，使用独立 `.preview-data/`，无需修改 `.env`。按 `Ctrl + C` 停止。若提示 5173 或 3100 端口被占用，先停止之前打开的开发服务，再重试。

## Windows 本地查看

```powershell
Set-Location 'J:\PRT-demo-hub-test'
npm ci
npm run dev
```

同样在这台 Windows 电脑打开 <http://127.0.0.1:5173/?intro=1>。此命令用于本机预览；Docker 正式更新仍使用 `scripts/update-docker.ps1`。

## 文件与更新

- `src/Login.jsx`：登录入口、三个阶段的固定播放顺序、后台自动暂停、浮层入场及失败回退。
- `src/Login.css`：全屏画面、半透明纸张材质、浮层入场及手机适配。
- `public/media/login-forest.mp4`：约 10 秒、1600 × 900 的 H.264 静音网页视频，约 1.8 MiB。
- `public/media/login-forest-landing.mp4`：约 3 秒的松果落地至静止片段。
- `public/media/login-forest-ambient.mp4`：松果固定、草叶摆动的 H.264 无缝循环片段。
- `public/media/login-forest-poster.jpg`：松果落地画面的静态封面及减少动态效果时的背景。
- `public/media/login-forest-opening.jpg`：开场视频的首帧封面。
- `public/media/login-paper-grain.svg`：轻微纸张颗粒纹理。

更新部署时同步完整源码，包含 `public/media/`，再构建镜像。无需新增环境变量或数据库迁移。
